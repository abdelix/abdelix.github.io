**camfr3** is a Python-based electromagnetic simulator and mode solver for nanophotonics, based on the
**eigenmode expansion (EME)** method. It is a port of [CAMFR](https://github.com/demisjohn/CAMFR) (CAvity Modelling
FRamework) to Python 3. I'm also modernizing it.

```sh
pip install camfr3
```

- **Documentation:** [abdelix.com/camfr3](https://abdelix.com/camfr3/)
- **Source code:** [github.com/abdelix/camfr3](https://github.com/abdelix/camfr3)
- **Package:** [pypi.org/project/camfr3](https://pypi.org/project/camfr3/)
- **Upstream:** [github.com/demisjohn/CAMFR](https://github.com/demisjohn/CAMFR)

camfr3 builds on the work of the original CAMFR authors and is distributed under the same GPL-2.0 license.
